---

## 📊 How It Works

1. Upload raw business communication  
2. System extracts structured tasks  
3. Repeated patterns are detected  
4. SOP is auto-generated  
5. Workflow graph is created  
6. Bottlenecks are highlighted  
7. AI Copilot answers contextual queries  

---

## 📈 Example Queries

- “What is our refund process?”  
- “Where are delays occurring?”  
- “Which task repeats most frequently?”  
- “Why did delivery timelines increase?”
